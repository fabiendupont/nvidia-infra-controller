# providers/firmware

Manages firmware updates for bare-metal hardware components. Skeleton — firmware logic is currently in Core (Rust); this provider will wrap it.

## Status

Skeleton provider. Registers the `firmware` feature capability with no routes or hooks. Firmware update logic is implemented in NICo Core (Rust) and will be exposed through this provider in a future phase.
